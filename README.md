# LPTEM simulator

This code is a modified version of the MATLAB code by Yao et al. [https://github.com/chenlabUIUC/simulatedLPTEM](https://github.com/chenlabUIUC/simulatedLPTEM) in Python that generates simulated LPTEM videos for various sample thicknesses and various electron beam dose rates a microscope. The position and in-plane orientation of the particles can be loaded from real LPTEM trajectories.
